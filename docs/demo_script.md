# Demo script (3 minutes)

Record from the deployed link on a real phone after the screen has been rehearsed twice without errors. Keep one phone fully cached as the primary device.

| Time | Scene | What the judges see | Fallback |
|---|---|---|---|
| 0:00 - 0:15 | The problem | One line on digital-arrest and KYC fraud and the named user: a first-time smartphone user in a Chhattisgarh town | Prepared slide |
| 0:15 - 0:45 | Message check, offline | Phone in airplane mode. Tap the "KYC (Hinglish)" example: red result with highlighted words and reasons. Tap "Bank debit alert" and "OTP message": both green | The saved examples are inside the app |
| 0:45 - 1:20 | Call check | Open a recorded digital-arrest clip (or the "Digital arrest call" example): transcript, stages heard, flagged phrases, tap a phrase to jump | The example call works with the service off |
| 1:20 - 1:45 | Reporting | "Money has left my account": the 1930 button, the checklist, copy the summary | None needed |
| 1:45 - 2:15 | Learn and score | A Chhattisgarhi lesson opened offline, a short quiz, the literacy score and the next lesson | Switch to Hindi if audio or the font misbehaves |
| 2:15 - 2:40 | Trends | The district chart with the demo-data label; send one anonymous report and show it queued | Seeded data |
| 2:40 - 3:00 | Evidence | Evaluation figures with the keyword baseline, then the honest limits slide | Static slide |

Bonus if time allows: scan a test QR from `docs/qr-test-codes` and show the result; open "On a call right now?".

## Presentation checklist

- The deck states the user, the problem, the modules and the architecture diagram.
- The evaluation slide shows test and challenge results with counts and names the limits.
- The live link and a QR code to it are on the closing slide.
- Every claim in the deck has a matching file in the repository.
- Two teammates can run the demo; one holds the cached phone.
- Name the existing anti-fraud tools the team actually checked on the comparison slide, and claim the specific differences (offline, three languages including Chhattisgarhi lessons, detection to reporting to learning in one flow) rather than "first of its kind".
