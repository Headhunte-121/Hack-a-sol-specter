# AI tool usage

| Tool | Used for |
|---|---|
| Claude Code (Anthropic) | Writing and refactoring code (web app, services, ML pipeline), unit and parity tests, template-based synthetic messages, lesson and quiz text, translations, documentation |

Every part of the code is explained in its folder's README or in comments, and each team member should be able to walk through it. Machine-generated text (messages, translations) is marked in `data/DATA.md` and in `docs/TESTING.md` where a human review is needed.
